# flag-leads — контакти на потенциални клиенти (фирма за знамена)

Python система, която обхожда публични източници, извлича **служебна**
контактна информация на организации и я записва в един систематизиран
Excel файл (`output/kontakti_znamena.xlsx`), категоризиран по таргет групи.

## Инсталация

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium        # нужно за eop, iisda, ntr_hotels
```

## Стартиране

```bash
python main.py --all                          # всички източници в приоритетен ред
python main.py --source namrb                 # само общините
python main.py --source business_bg --category hoteli
python main.py --export-only                  # само Excel от наличните JSON-и в data/
```

Всеки скрейпър записва междинен JSON checkpoint в `data/` — при прекъсване
следващият пуск продължава оттам. Excel файлът се генерира автоматично в
края на всеки пуск.

Демо на пайплайна без мрежов достъп:

```bash
cp tests/fixtures/demo.json data/
python main.py --export-only
# изтрийте data/demo.json преди реално обхождане!
```

Тестове (дедупликация с изкуствени дубликати, валидация, Excel):

```bash
python tests/test_pipeline.py
```

## Excel изход

`output/kontakti_znamena.xlsx` съдържа:

- **Всички** — обединени, валидирани и дедуплицирани записи;
- по един лист на категория: Институции, Общини, Училища, Посолства,
  Бизнес, Хотели, Спортни клубове, Събития, Църкви;
- **Статистика** — брой записи по категория, % с имейл, % с телефон,
  дата на генериране.

Форматиране: замразен header, автофилтри, автоширина, оцветен header.
Дедупликация: по нормализиран телефон **и** по имейл (записите от два
каталога се сливат, празните полета се допълват). Телефоните се
нормализират към `+359…` (чуждите номера на посолствата запазват своя
международен префикс), имейлите се валидират през regex.

## Технически бележки

- **Rate limiting**: мин. 2 s между заявки към един домейн (`config.RATE_LIMIT_SECONDS`).
- **robots.txt**: проверява се за всеки домейн; при забрана URL-ът се
  логва и пропуска. Ако цял източник е забранен за обхождане, той трябва
  да се свали ръчно — отбележете го в тази таблица.
- **User-Agent**: `FlagLeadsBot/1.0` — честна идентификация, без имитация
  на браузър при httpx скрейпърите.
- **Retry**: 3 опита с exponential backoff при 5xx/timeout; при **403/429
  скрейпърът спира и логва** — не заобикаляме блокировки и CAPTCHA.
- **Логове**: `logs/<източник>.log` + конзола; в края на всеки пуск се
  отпечатват брой обходени страници, записи и грешки.

телефони на организации) от публични регистри и каталози — не се събират
лични имена с лични имейли/телефони на физически лица (лични кутии в
безплатни пощи се филтрират автоматично в `scrapers/base.py`). Данните са
предназначени за B2B контакт по служебни канали на основание легитимен
интерес (чл. 6, ал. 1, б. „е“ GDPR). При имейл кампании е задължително
всяко писмо да съдържа ясна opt-out възможност, а отписванията да се
спазват. Не заобикаляйте CAPTCHA, login форми или технически защити;
спазвайте Terms of Service на частните каталози.
